
Поскольку мы настраиваем проект для **локальной разработки с отладкой в VSCode**, мы запустим в Docker **только базу данных и очередь задач**, а сам код (FastAPI, Celery, Streamlit) будем запускать через отладчик VSCode. 
Это даст вам возможность ставить точки останова (breakpoints) и видеть переменные в реальном времени.



---

### 🛠 Шаг 1: Проверка файла `.env`

Убедитесь, что в корне проекта создан файл `.env` и в нём **раскомментированы** строки для локального подключения (убран символ `#` в начале):

```env
# --- AI ---
OPENAI_API_KEY=sk-ваш_реальный_ключ_здесь
OPENAI_BASE_URL=https://api.openai.com/v1

# --- База данных и Очередь (ДЛЯ ЛОКАЛЬНОГО ЗАПУСКА) ---
DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5432/competitors_db
REDIS_URL=redis://localhost:6379/0

# --- Безопасность ---
API_KEY=sk-test-123

# --- Streamlit ---
API_BASE_URL=http://localhost:8000
```


---

### 🐳 Шаг 2: Запуск инфраструктуры в Docker

Откройте терминал в VSCode (убедитесь, что вы в корне проекта) и выполните команду для запуска **только** PostgreSQL и Redis в фоновом режиме (`-d`):

```bash
docker compose up db redis -d
```

**Что произойдет:**
1. Docker скачает образы `pgvector/pgvector:pg15` и `redis:7-alpine` (если их ещё нет).
2. Создаст и запустит два контейнера.
3. Пробросит порты `5432` (PostgreSQL) и `6379` (Redis) на ваш локальный компьютер.

**Проверка успешности:**
Выполните команду:
```bash
docker ps
```
Вы должны увидеть два работающих контейнера: `ca_db` и `ca_redis` со статусом `Up` и зеленым индикатором `healthy`.

### 💻 Шаг 3: Запуск приложений через VSCode Debugger

Теперь, когда база данных и очередь готовы, мы запустим основной код локально.

1. В VSCode откройте панель **Run and Debug** (значок жука и play слева или `Ctrl+Shift+D` / `Cmd+Shift+D`).
2. В выпадающем списке сверху выберите конфигурацию и нажмите зелёную кнопку Play ▶️:

#### 🔹 3.1. Запуск FastAPI (Backend)
- Выберите: **`Python: FastAPI`**
- *Ожидаемый результат:* В терминале появится надпись `Uvicorn running on http://0.0.0.0:8000`.
- *Проверка:* Откройте в браузере http://localhost:8000/health. Должно вернуться `{"status":"ok","version":"1.4"}`.

#### 🔹 3.2. Запуск Celery Worker (Обработка задач)
- Выберите: **`Python: Celery Worker`**
- *Ожидаемый результат:* В новом терминале появится лог Celery с надписью `celery@ваш_компьютер ready` и списком зарегистрированных задач (`analyze_competitors_task`).
- *Важно:* Этот воркер должен работать постоянно, пока вы тестируете приложение.

#### 🔹 3.3. Запуск Streamlit (Web UI)
- Выберите: **`Python: Streamlit`**
- *Ожидаемый результат:* В терминале появится ссылка `You can now view your Streamlit app in your browser.`
- *Проверка:* Откройте http://localhost:8501

### 🎯 Шаг 4: Тестовый запуск полного цикла

1. Откройте **http://localhost:8501** в браузере.
2. В боковой панели нажмите кнопку **🏥 Проверить API** (должно показать ✅ API доступен).
3. Заполните форму:
   - **Ниша:** `кофейни`
   - **География:** `Москва`
   - **Запрос:** `спешелти кофе с веганскими десертами`
4. Нажмите **🚀 Запустить анализ**.
5. Наблюдайте, как в интерфейсе меняется статус: `⏳ Ожидание` → `🔍 Поиск...` → `🧠 Генерация...` → `✅ Успех`.
6. В терминале **Celery Worker** вы увидите логи выполнения задачи.
7. В терминале **FastAPI** вы увидите лог `Task <id> sent to queue`.

*(Если вы поставите красную точку (breakpoint) в файле `pipeline.py` на строке `urls = search_competitors(...)`, выполнение остановится, и вы сможете inspect'ить переменные в VSCode).*

### ⚠️ Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| **Port 5432 is already allocated** | У вас уже запущен локальный PostgreSQL. Остановите его через службы Windows или измените порт в `.env` и `docker-compose.yml` (например, на `5433:5432`). |
| **Port 6379 is already allocated** | Аналогично, другой Redis мешает. Остановите его или смените порт на `6380:6379`. |
| **ModuleNotFoundError: No module named 'psycopg'** | Убедитесь, что в VSCode выбран правильный интерпретатор: нажмите `Ctrl+Shift+P` → `Python: Select Interpreter` → выберите путь к вашему `.venv`. |
| **Connection refused to Redis/DB** | Убедитесь, что контейнеры запущены: `docker ps`. Если нет, запустите `docker compose up db redis -d` заново. |

### 🔄 Альтернатива: Полный запуск ВСЕГО в Docker (без VSCode отладки)

Если вы не хотите запускать приложения по отдельности через VSCode, а хотите просто поднять всё одной командой (как на продакшене):

1. В `.env` верните настройки для Docker:
   ```env
   DATABASE_URL=postgresql://postgres:postgres@db:5432/competitors_db
   REDIS_URL=redis://redis:6379/0
   API_BASE_URL=http://api:8000
   ```
2. Выполните в терминале:
   ```bash
   docker compose up --build
   ```
3. Откройте http://localhost:8501
